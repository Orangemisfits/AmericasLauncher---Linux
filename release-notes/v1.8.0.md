What's new in v1.8.0:
- The Linux project is shelved and removed from the repository. Releases are Windows-only. The README now shows the build status: Windows working, Linux work in progress, Mac not planned.
- The Pipeline option is gone. The game collects its cache while you play, so by the second or third time you play, the pipelines are built.
- The Resolution option is gone (it did not work).
- New: a short notice appears when you click Launch Game, about the removed Pipeline option, the Xbox Series S / X option (try the other one on a black screen or crash) and the recommended settings.
- New: GPU selector (AMD / Nvidia) in Runner Settings. The launcher applies the settings each runner's own project recommends for that card. Runners whose project names no difference use the same settings for both cards (DexNom has separate AMD and Nvidia settings). Settings > Recommended Settings shows them and what they do. Your own Launch Options win over them, and they can be switched off.
- Fix: a runner card could stay yellow after the runner was updated. It now turns green.

Installation: download AmericasLauncher-v1.8.0-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
