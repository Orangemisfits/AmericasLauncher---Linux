## 🔧 Hotfix: Self-Updater Downloads Correct Platform Zip

### What's Fixed

- **Auto-update now downloads the correct zip for the current platform** — Since v1.7.0, releases include both `win-x64.zip` and `linux-x64.zip`. The updater was taking the first `.zip` it found in the asset list, which could be the Linux zip if that build finished first. It now specifically looks for the zip matching `win-x64` on Windows (and `linux-x64` on Linux), with a fallback to any zip for older single-asset releases.
- **Clear error if wrong zip is downloaded** — If `AmericasLauncher.exe` is not found in the extracted zip, an explicit error is shown instead of silently doing nothing.
