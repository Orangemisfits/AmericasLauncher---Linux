What's new in v1.8.8:
- New: **Nvidia - VIctory** page under Launch in the left sidebar. Nvidia - VIctory Based moved there from the runner cards because it comes with its own scripts.
  - **Install**: downloads the runner's repository with git (or updates it).
  - **Set Game folder and exe**: opens `victory.toml` in the runner's folder; if it does not exist, it is created from `victory.example.toml` first. Available after Install.
  - **Get AMD FSR** runs `Get-AMD-FSR.cmd`, **Get NVIDIA DLSS** runs `Get-NVIDIA-DLSS.cmd`, **Play with Framegen** runs `PLAY_FRAMEGEN.cmd` and **Play Normal** runs `Play-VIctory.cmd`. Each opens in its own command window; nothing is written to the launcher log. Play Normal uses your Game Folder from Settings as `VICTORY_GAME_DIR` when it is set.
  - Once you are inside the game, press **F1** to open the game's own settings menu.
- The Nvidia runner no longer has recommended settings in the launcher: it sets itself up.

Installation: download AmericasLauncher-v1.8.8-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
