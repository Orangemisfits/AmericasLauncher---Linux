## 🐧 Native Linux Port

Americas Launcher is now available natively on Linux!

### What's New

- **Linux native build** — A fully native Linux port built with Avalonia UI (`net8.0`, `linux-x64` self-contained).
- **Full feature parity** — Runner grid, Runner Status colors, Runner Settings (Pipeline / Series S / Resolution), Stop Game, Console log, Cool Start, and Settings view all work on Linux.
- **Wine fallback** — Windows `.exe` runners that don't have a native Linux binary run automatically through Wine.
- **All 9 runners supported** — XCL, Belabug, Dexnom, KLBF-LAB, Victory (Original), hyphenn, AvatarManz, Nvidia, CGBJ.

### Downloads

| Platform | File |
|---|---|
| Windows x64 | `AmericasLauncher-v1.7.0-win-x64.zip` |
| Linux x64 | `AmericasLauncher-v1.7.0-linux-x64.zip` |

### Notes

- The Windows build is **unchanged** — all fixes from v1.6.x carry over.
- Linux binary requires a modern distro (Ubuntu 22.04+, Arch, Fedora 38+, etc.).
- If your runner is a `.exe` file, install Wine for automatic fallback support.
