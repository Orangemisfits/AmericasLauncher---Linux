What's new in v1.9.3:
- Fixed: a GitHub sign-in window (Git Credential Manager) could open when a runner was installed or updated, and signing in did nothing or crashed the launcher. It appeared when a runner's repository was not found or not public (for example a runner that was deleted, or a mistyped Custom Runner URL). The launcher now never lets git ask for a login: every git and build step runs without credentials.
- If a download fails with "repository not found", the log now says the runner may have been deleted or the URL is wrong, and to check the GitHub URL for a Custom Runner in Settings.

Installation: download AmericasLauncher-v1.9.3-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
