What's new in v1.5.6:
- Fix: the game (victory.exe) could stall or never render while the launcher was open. The game's output is now written to a log file (`%LocalAppData%\AmericasLauncher\logs\game.log`) instead of a pipe owned by the launcher, and the launcher's log box is updated in batches and kept to a bounded size. The game can no longer be blocked by the launcher, and it keeps running if you close the launcher.
- New: choose Xbox Series X or Xbox Series S per runner, next to the pipeline toggle (VIctory forks use `--console`, XCL uses `XCL_DEVICE_TYPE`). Series S upscaling in VIctory forks may need the FidelityFX SDK path (`VICTORY_FIDELITYFX_DIR`).
- New: the launcher checks for updates on startup and shows "- New Update available" next to the title and a yellow dot next to Settings. The version no longer appears next to the title.

Installation: download AmericasLauncher-v1.5.6-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
