What's new in v1.8.9:
- Nvidia - VIctory page: new **Check for updates** button next to Install tells you if the runner has a newer version.
- **Set Game folder and exe** now explains what to enter: you do not need to set `game_dir = 'C:\gamefile'` literally; set the location of the folder the game is in (not the exe).
- **Play with Framegen** and **Play Normal** stay locked until you have clicked **Set Game folder and exe** once. After that they stay unlocked, even after the runner is updated.
- Removed leftover Nvidia build/DLSS-mode settings; only the page's buttons remain.

Installation: download AmericasLauncher-v1.8.9-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
