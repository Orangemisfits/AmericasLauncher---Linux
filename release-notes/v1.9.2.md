What's new in v1.9.2:
- **Nvidia - VIctory** page: the **DLSS settings** box can be opened and closed and starts closed.
- DLSS settings are locked until the game's settings file exists. Install the Nvidia - VIctory runner and run the game once: the file is created automatically, then the settings unlock.
- New **Mouse and keyboard** option (the game's F1 > KEY BINDINGS) with a **Keybinds** button that lists the default keys. In the game you can change the keys from F1.
- **Settings**: Check for Updates and Auto Update are now at the very top of the page.
- **Belabug** and **AvatarManz** runners were removed. There are now three custom slots: **Custom Runner 1, 2 and 3**, each with its own GitHub URL in Settings (sections 1, 2 and 3).

Installation: download AmericasLauncher-v1.9.2-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
