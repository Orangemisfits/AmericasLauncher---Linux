Hotfix v1.7.5:
- Fix: building runners failed with `link.exe failed: exit code: 1181` on PCs where Visual Studio Build Tools were installed without the Windows SDK. The launcher now detects the missing Windows SDK and installs it (accept the Windows permission prompt). If it cannot, the log says exactly what to tick in the Visual Studio Installer.
- Fix: Rust/cargo build commands now run through a script file with the Visual Studio environment loaded quietly. This removes the stray "The system cannot find the file specified." message and finds Visual Studio of any year/edition. If the environment is incomplete, the log now says so.
- Fix: launcher self-update. Releases are Windows-only again, so older launchers (v1.7.0-v1.7.2), which download the first zip they find, no longer pick the Linux zip and restart the old version. The update script was also made robust: it waits for the exact process, retries the copy, never hangs on a hidden prompt, and writes `%TEMP%\AmericasLauncher-update.log`. Startup update-check failures are written to `%LocalAppData%\AmericasLauncher\update.log`.
- If you are on v1.7.2 or older and the in-app update still restarts the old version, download AmericasLauncher-v1.7.5-win-x64.zip below once and extract it over your launcher folder; later updates work in-app.

Installation: download AmericasLauncher-v1.7.5-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
