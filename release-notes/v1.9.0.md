What's new in v1.9.0:
- **Nvidia - VIctory** page reworked: **Install** now downloads the newest `victory.exe` from the runner's releases. It first asks for the folder where it should be saved: that must be the folder with your game files and the game's exe. **Check for updates** tells you if a newer release exists, and **Play with Framegen** starts the downloaded `victory.exe`.
- The Nvidia page has its own **log** that shows victory.exe's output, with an input box that is always there so you can type to it (for example to answer its first-run question).
- **Set Game folder and exe**, **Get AMD FSR**, **Get NVIDIA DLSS** and **Play Normal** were removed from the Nvidia page. In the game, press **F1** to open its settings.
- The **Launch log** now also has an input box that is always visible; what you type goes to the running game.
- **Home** is open: a big "Welcome to Americas Launcher" and a collapsible **Release Notes** section (closed by default) with every release, newest first.

Installation: download AmericasLauncher-v1.9.0-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
