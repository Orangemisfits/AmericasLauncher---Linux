## 🆕 What's New in v1.8.5

### 🏠 Home (Coming Soon)
- A **Home** button has been added to the top of the left sidebar. It is not functional yet — it will be enabled in a future update.

### 📦 Runners Directory
- New **Runners** tab in the sidebar lists all supported runners with their name, notes, and a one-click **Open GitHub ↗** link that opens the runner's repository in your browser.

### 🎮 3-State Console Selection
- The **Console** button now cycles through **three** states: `Xbox Series X` → `Xbox Series S` → `Console: OFF`.
- When set to **OFF**, no console arguments or environment variables are passed to the runner — useful for runners that don't need them.

### 🖥️ GPU: Off Mode
- The **GPU** button now cycles through three states: `GPU: AMD` → `GPU: Nvidia` → `GPU: Off`.
- When set to **Off**, recommended settings are disabled for that runner, letting you launch with only your own Launch Options.

### ⚙️ Review Before Build is Now ON by Default
- **Update Source** and **Build** buttons are now **separate by default** for all new installs. The old combined "Install / Update" flow can still be restored in Settings by toggling Review Before Build off.

### ⚡ Nvidia — VIctory Based: DLSS & Interactive Launch
- A new **Build with DLSS** button appears when the Nvidia runner is selected.
  - Runs `Get-NVIDIA-DLSS.cmd` first, then `PLAY_FRAMEGEN.cmd` — both shown inside the launcher log.
  - `PLAY_FRAMEGEN.cmd` prompts you to pick an option (1–6): type your choice in the new **input bar** that appears at the bottom of the log and press Enter or click **Send**.
- **Launch Game** for Nvidia now runs `play-victory.cmd` directly (if present in the runner folder) instead of launching through the launcher's own argument builder.
- Recommended settings are **disabled** for Nvidia — VIctory Based; the runner's own scripts manage them.

### 📝 Persistent Release Note
- The "Updated to …" release note popup **no longer auto-closes**. It stays open until you click the ✕ button.

### 🔧 Custom Runner
- A new **Custom Runner** slot appears as the first card (top-left of the grid).
- Go to **Settings → Custom Runner** and paste any GitHub repository URL (without `.git` at the end). Example: `https://github.com/Marvisak/VIctory`
- Once a URL is saved, the Update Source, Build, and Launch Game buttons unlock for that runner.
- The gear icon (⚙) on the Custom Runner card always takes you directly to the Custom Runner settings — even before it is installed.
- Custom Runner starts with no recommended settings.

### 🗂️ Runner Order

| | Left | Centre | Right |
|---|---|---|---|
| **Row 1** | Custom Runner | XCL | Nvidia — VIctory Based |
| **Row 2** | VIctory (Original) | Belabug | CGBJ |
