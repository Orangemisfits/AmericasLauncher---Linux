## 🔧 Hotfix: Self-Updater Fix

### What's Fixed

- **Auto-update now correctly replaces the launcher** — The updater was using `AppContext.BaseDirectory` to find the install directory, which for single-file published apps points to a temporary extraction folder in `%TEMP%`, not the actual install location. It now uses `Environment.ProcessPath` (the real `.exe` path on disk) to find the correct install directory.
- **Launcher now reliably restarts after update** — The update script now explicitly launches `AmericasLauncher.exe` from the resolved install directory after `robocopy` finishes, instead of re-using the old process path variable.
- **robocopy exit code handling fixed** — `robocopy` returns 1 when files are successfully copied (not 0), which was causing the restart command to be skipped in some shells. The script now treats exit codes 0–7 as success (robocopy bitfield convention) and only errors on codes ≥ 8.
