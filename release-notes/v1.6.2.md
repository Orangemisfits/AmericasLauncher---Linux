Hotfix v1.6.2:
- Fix: Visual Studio Build Tools were not detected when you installed them yourself, so setup stopped with "could not be verified after installation". Detection now also finds the C++ linker and the usual install folders, and if Visual Studio is installed without the "Desktop development with C++" workload, the launcher adds it through the Visual Studio Installer (accept the Windows permission prompt).

Installation: download AmericasLauncher-v1.6.2-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
