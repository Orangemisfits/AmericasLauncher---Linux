## 🔧 Hotfix: Runner Update — Git Diverging Branch Fix

### What's Fixed

- **Runner update no longer fails on diverging branches** — Previously used `git pull --ff-only` which aborts when the upstream has been rebased or force-pushed. Now uses `git fetch --prune origin` followed by `git reset --hard <upstream>` so the local source is always synced to the latest remote state regardless of history divergence.
- Runner source directories are never modified by the launcher, so discarding local state is always safe.
