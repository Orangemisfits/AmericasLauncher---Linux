What's new in v1.9.1:
- **Nvidia - VIctory** page: new **DLSS settings** box next to Play with Framegen. It edits the game's own settings file (`%LOCALAPPDATA%\victory\victory-settings.txt`, the one the F1 menu saves to) with the same choices as the F1 menu: DLSS mode, Frame Generation (2x to 6x), Frame Gen type, Frame Rate Cap, Console, Series X/S Picture and DLSS model, plus tick boxes for MFG Unlocker, FPS at the top, Stats panel (F3), Fullscreen, Mouse capture and Preload shaders.
- On Series S the picture size and the DLSS mode are one setting, as in the game: 1080p is DLAA, 720p is Quality, 626p is Balanced and 540p is Performance. Change one and the other follows.
- **Save settings** writes only these settings; every other line of the file stays as it is. Tick boxes: ticked is ON, unticked is OFF. Preload shaders is for the next start only.

Installation: download AmericasLauncher-v1.9.1-win-x64.zip below, extract it anywhere and run AmericasLauncher.exe. If you already have the launcher, use Settings > Check for Updates.
